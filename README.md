## Project Overview

This project is developed as part of Task 1 of the Full Stack Web Development Internship.

The objective of this task is to design and develop a professional personal portfolio website that showcases:

• Personal profile  
• Technical skills  
• Projects  
• Resume information  
• Contact form with backend integration  

This project follows a full-stack architecture with separate frontend and backend folders.

------------------------------------------------------------

## Technologies Used

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

## How to Run the Project Locally

1. Open the project folder.
2. Open terminal inside the "server" folder.
3. Run:
   npm install
4. Start the server:
   node server.js
5. Open your browser and visit:
   http://localhost:5000
